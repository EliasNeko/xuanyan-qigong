# 用到的工具与依赖

## 运行环境

| 项 | 值 | 备注 |
| --- | --- | --- |
| Python | 3.15.2 | 打包与运行都是它 |
| 浏览器 | Microsoft Edge | Playwright 用 `channel="msedge"`，没装 Edge 要改配置 |
| 系统 | Windows 10/11 | 界面依赖 Tk、安装器依赖 PowerShell |

## 直接依赖

| 库 / 工具 | 用途 | 为什么是它 |
| --- | --- | --- |
| **playwright** | 驱动 Edge：导航、点击、注入 JS、读 frame | 走真实浏览器与真实页面，不用逆向接口，抗改版能力强 |
| **fontTools** | 读 ttf 的 cmap、字形名 | 字体加密还原的唯一可行路径 |
| **Pillow** | 背景裁切/模糊、磨砂片、按钮素材烘焙、截图 | 界面皮肤全靠它现画 |
| **numpy** | 图像处理辅助 | 随 Pillow 一起用于像素级处理 |
| **tkinter** | 主窗口、向导、弹窗 | 系统自带，打包体积小，够用 |
| **sqlite3** | 本地题库 | 标准库，单文件、免服务 |
| **urllib** | 课程页/接口抓取 | 标准库，够用 |
| **PyArmor** | 源码加密 | 发布版里不出现明文 .py |
| **PyInstaller** | 封装成 exe | 单目录分发，带上 Edge 驱动与素材 |

> PyArmor 与 PyInstaller 只在「发布给自己/同学」时用到，运行本身不需要。

## 外部服务（都不是必需）

| 服务 | 用途 | 没有它怎么办 |
| --- | --- | --- |
| 学习通网页版 | 被操作的对象 | 没它就没得刷 |
| 豆包网页版（免费） | 没题库时答题 | 只能靠本地题库 + 蒙题兜底，正确率大幅下降 |

## 为什么没有用（评估过但放弃的）

| 方案 | 放弃原因 |
| --- | --- |
| 搜索引擎查题（360 / 百度） | 实测连续 5 题全撞滑块验证码，命中 0/5；验证码页只有 400 字节，等于不可用 |
| 直接打学习通接口 / 伪造请求 | 违反「走真实页面」的设计前提，风控更容易识别，也会因参数加密而失效 |
| 本地大模型（Ollama） | 目标机器上普遍没装，体积与显存门槛高；留给高级用户自己接 `providers` |
| 付费 API（OpenAI 等） | 用户明确不想花钱；豆包网页版免费且效果够用 |
| 逆向学习通的字体加密算法参数 | 换课就变，维护成本高；cmap 反查是通用解 |

## 打包与安装

| 环节 | 工具 | 产出 |
| --- | --- | --- |
| 加密 | PyArmor `gen` | 加密后的 `app_src/`（字节码 + 运行时 pyd） |
| 封装 | PyInstaller（windowed） | `dist/玄眼奇工/玄眼奇工.exe` |
| 安装器 | PyInstaller + 自写 Tk 安装程序 | `dist_inst/玄眼奇工安装程序.exe` |
| 快捷方式 | PowerShell `WScript.Shell` | 桌面 / 开始菜单 .lnk |
| 卸载 | 生成的 `卸载 玄眼奇工.bat` + HKCU 卸载项 | 控制面板可卸载 |

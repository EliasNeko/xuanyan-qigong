# v1.0.0（2026-11-18）首个公开版本

## 背景

从「能跑起来」到「敢给别人用」之间，这一版补齐了三件事：**登录别让人手动折腾**、**别乱交卷留下 0 分**、**别在打不开的页面上死循环**。

## 这一版能做什么

- 打开就是登录向导：学习通扫码（自动勾下次自动登录）/ 账密小窗 + 豆包抖音扫码，两个都登过就不再打扰。
- 自动挑下一节（已解锁 + 未完成），看视频、答弹题、到 91% 判定任务点、提前切章节测验。
- 章节测验：解析 + 字体解密 + 逐题取答案 + 自检 + 提交 + 读分 + 查重做。
- 界面：进度条、「当前小节」、「上次跑到哪」、刷课记录（优秀 / 及格 / 不及格）。
- 发布：加密 + 安装包。

## 关键技术点

- 任务点判定：只认 `.ans-job-icon` 外层的 `ans-job-finished` 类（学习通自己也这么判）。
- 章节测验选项：li[qid] + hidden input 的真实结构（没有 radio），自检查 hidden 的 value。
- 字体加密：多候选 @font-face 逐个 cmap 命中打分，只还原被认领的码位。
- AI 答题：常驻线程 + 队列（避开 sync Playwright 的线程限制），快照增量取答案。
- 发布：单文件 ≤ 33KB 是 PyArmor 试用版的硬限制，因此把界面拆成 app / app_ui / app_hist / wizard 四块。

## 已知问题（随版本一起公开）

- 提交后无重做入口的分数改不了。
- 只覆盖视频 + 章节测验两类任务点。

# v2.1.0 — v2 重置版：任务点按类型做、目录实时同步、范围自己选

发布日期：2026-11-19

v2.0.2 之后，用户反馈集中在三件事上：**「有的任务点根本不是视频也不是选择题」**、
**「计时休息反而添乱」**、**「界面字看不清、范围不能选」**。这一版就是照着这三件事重做的，
所以内部叫「v2 重置版」（版本号只涨次位）。

## 为什么改

1. **任务点类型不止两种**。同一门课里混着视频、文档（Word / PDF / PPT）、章节测验、
   填空 / 简答 / 计算题、讨论、直播……老师自己配的，每门课都不一样。旧版写死
   「先看视频 → 再做测验」，遇到文档任务点会直接跳过，遇填空简答会抓瞎。
2. **节奏护栏不听话**。v2.0.0 的分段 / 休息 / 课程冷却 / 每日上限本意是「像真人」，
   但实际用起来是「我点开始刷，它让我等 40 分钟」。用户要的是「我选好范围，它按顺序做完」。
3. **界面信息密度低**。字号 9 到处是、对比度不够；目录只能一节节勾，不能「从这刷到那」。
4. **封面与安装体验**。logo 是旧版淡蓝樱花艺术字，和「工具」定位不够贴；安装器也没提醒
   杀软会误报。

## 改了什么

### 1) 任务点按类型做（重写 `taskpoint.py`）

先把这一节的任务点全部列出来：标题、图标 class、完成状态；再按图标 class 优先、
标题其次猜类型（`video` / `doc` / `quiz` / `discuss` / `live` / `unknown`）；
每一类给一个「怎么才算完成」的执行器：

| 类型 | 怎么算完成 | 备注 |
| --- | --- | --- |
| 视频 | 图标变成 `ans-job-finished` | 91% 先问一次，没达标播到 96%，再不行播到结尾 |
| 文档 | 图标变成 `ans-job-finished` | 每一层能滚的容器都滚到底、点「下一页 / 继续」；PDF 只吃滚轮就把指针挪到内容区滚 |
| 章节测验 | 提交成功、读到分数 | 照旧逐题作答 + 自检 + 80 分重做 |
| 填空 / 简答 / 计算题 | 输入框有内容、提交成功 | 没有选项可点，把题干交给 AI 要一段文字答案；拿不到就留着给人工补 |

讨论 / 直播 / 未知类型：识别出来、跳过、日志里写清楚为什么不碰。

### 2) 一个做完才转下一个

`runner.do_section` 不再写死顺序，而是「读任务点 → 做第一个没完成的 → 回读图标确认
`ans-job-finished` → 做下一个 → 全部完成才回目录」。中途窗口被关、页面被弹回首页，
下一轮重新进课、重扫目录，接着刷，不会从第一个重来。

### 3) 目录实时同步

每轮回到章节树都重新扫一遍：服务端说「已完成」的小节直接写进本地进度（换电脑 / 重装后
「接着上次跑」也成立）；任务点做完立刻反映到目录和进度条。

### 4) 去掉计时与休息限制

删掉 v2.0.0 的节奏护栏（`pace.py` 的会话计时 / 段间休息 / 课间冷却 / 每日上限入口不再
挂到界面上）：不再「刷 80 分钟停 40 分钟」，不再「换课等 3.5 小时」，一门课做完直接换下一门。
留下来的节奏是**目录顺序**本身。

### 5) 起止范围选择

- 列表里勾小节（☐）；
- 或点「从这里开始 ▸」定起点、再点「◂ 到这里结束」定终点，按目录顺序选一段（含两端）；
- 闯关课里锁着的小节标「锁定 · 可预约」：勾了也先留在队列里，前面做完会自动解锁再重扫。

### 6) 界面重做

- 四块信息 + 一个动作：① 我的课程 + 任务点目录、② 豆包 AI 答题、③ 任务点与范围、
  ④ 运行设置、⑤ 开始刷课；
- 字号整体拉高（正文 9→10、标题 14），说明文字改深色，磨砂卡片重新切片；
- 顶栏 logo 换新、作者与版本号并排，不再压到看板娘；
- 「播放倍速 / 静音 / 兜底 / 刷多少节 / 超时跳过 / 答题截图 / 试填不交」全在 ④ 里。

### 7) logo 与图标

重画一版「猫耳 + 玻璃质感」的淡蓝字标（保留猫耳），程序图标、安装包图标一起换；
安装包里的图标同步。

### 8) 安装器

- 加一块「如果安装或启动被安全软件拦了」的黄色提示：360 / 火绒 / Defender 可能误报，
  先确认文件名是「玄眼奇工」再点允许，或手动加信任；程序不下载额外内容、不改系统设置；
- 安装说明补「装在用户目录、不需要管理员权限、卸载走卸载 bat」。

### 9) 内部：`answers.py` 拆成四个模块

PyArmor 试用版对单个脚本有体积上限，`answers.py`（725 行）加密到一半报
`out of license`。把六个 provider 按体积拆进：

- `answers_base.py`：`SCHEMA` / `LLM_PROMPT` / `Bank` / `LocalProvider` / `LLMProvider` / `HttpProvider`
- `answers_web.py`：`WebProvider`
- `answers_ai.py`：`AiProvider`
- `answers.py`：汇总 + `Chain`

对外导入不变（`from .answers import Bank, Chain`）。

## 验证

- 四个拆分模块分别 `pyarmor gen` 均成功，整包加密打包（PyArmor 9.3 + PyInstaller）通过；
- 打包产物自检：`TITLE 用户登录` / `URL https://passport2.chaoxing.com/login?fid=&refer=` / `OK`；
- 安装包 96.3 MB，装到 `%LOCALAPPDATA%\玄眼奇工` 后启动、自检、卸载项均正常；

## 升级

直接跑新安装包覆盖安装。`config.json`、登录态（`%LOCALAPPDATA%\LearnAuto`）、刷课记录都保留。

## 还留着的问题

- 讨论 / 直播 / 问卷类任务点仍只识别不处理（这类要么需要人发言，要么需要签到）；
- 文档任务点靠「滚到底 + 点下一页」触发完成，个别站点若把完成判定放在别的交互上会读不完成，
  日志里会写「还没算完成」；
- 填空 / 简答依赖 AI 答案质量，拿不准的建议勾「试填不交」自己核对；
- 起止范围按目录顺序，不支持「跳着选」——跳着选在闯关课里没有意义（后面的锁着）；
- PyArmor 是试用版，单文件仍有体积上限，以后某个模块再长大还要继续拆。

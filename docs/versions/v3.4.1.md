# v3.4.1 — 一块一块地做：按网页结构枚举任务点，风控来了就停下等你

发布日期：2026-11-19

## 为什么改

v3.4.0 还是「在页面上找第一个视频，播完再找下一个」。数学课、素养课的真实页面不是这样长的：一个标签（探职场 / 学知识）下面竖着堆**好几个**任务点块，每块自己一个 `iframe`。
按「第一个 video」的思路走，就会出现这些事：

- 第一个视频明明已经打勾了，脚本还在播它，第二个看都不看；
- 第一个播完，脚本以为自己已经做完这一节，直接跳走；
- 播放器重开同一段换了个 token，脚本把它当成「第 2 段、第 3 段」，同一条视频越播越多；
- 你想自己点一下第二个视频，脚本下一秒又把第一个的视频 play() 顶回来。

v3.4.1 不再猜。直接读页面的结构。

## 改了什么

### 1. 先枚举任务点块，再一块一块地播

打开的任务点页里，每个视频块长这样：

```html
<p class="editor-iframe" sequence-id="3">
  <div class="ans-attach-ct videoContainer ans-job-finished">
    <div class="ans-job-icon ans-job-video" aria-label="任务点已完成"></div>
    <iframe src="/ananas/modules/video/index.html?v=..."></iframe>
  </div>
</p>
```

现在按 `iframe[src*="/ananas/modules/video/"]` 把这一页的块从上到下列出来，每块拿自己的 `content_frame()` 播放：

- `aria-label` 里有「已完成」或容器带 `ans-job-finished` → 这块跳过，日志写「第 1 块「案例3.1…」页面标了已完成 → 跳过」；
- 没做的块先滚到眼前、必要时点一下把播放器唤醒，再播；
- 播完（或页面说完成）换下一块，播到没有未完成块为止。

这样「一个任务点半路挂着两个视频」「一个标签下堆两个任务点」都走同一条路。

### 2. 完成判定只认页面自己说的

视频只要页面亮出「任务点已完成」，立刻 `pause()` 收工，不陪着进度条走到 100%。那条「进度条 91% 就问一次系统」也保留着，做二次确认。

### 3. 你手动暂停、手动拉进度条，脚本不跟你抢

保活调用带了 `soft`，元素上被标成「用户操作」且处于暂停时不再 `play()`；你拉回开头也不再记成「播放器重播」，卡住分支也不会把进度往回退 3 秒。

### 4. 弹出风控 / 验证码：停手，把窗口搬回屏幕，等你

「【9010】操作异常，请输入图片中的验证码」这种页一出现：

- 脚本立刻停手，不刷新、不重试、不猜答案（反复提交错答案最招风）；
- 后台静音跑（窗口藏在屏幕外）时，把窗口搬回屏幕正中并放到最前；
- 日志和监视屏都写「要你输一次验证码」；
- 你输完提交、风控页消失，它自己接着刷，再把窗口送回屏幕外。

等 10 分钟还没人处理，就带一句提示收工。

### 5. 纯图片任务点：试一次就走，记「要人工」

「明要点」这类 0 个字、几张图的任务点，网页端根本不往服务端记完成（抓包零上报）。现在只停 6 秒确认一次，没完成就标成「需要人工」，换下一节去刷 —— 不再对着它滚几分钟。

同一节里刚标过「要人工」的任务点，再进这一节不会重试第二轮。

### 6. 测验不再等时长

章节测验答完就交（只留 2~6 秒「再核对一遍」的停顿），不再因为「做得太快不像人」干等 45 秒。

## 怎么验证的

- `python -m compileall -q learn_auto app.py pack`、`python -m pyflakes learn_auto` 无 undefined name。
- 内嵌 JS 用 `node --check` 逐个过语法。
- 驱动脚本在「通用职业素养」上实测：探职场第 1 块跳过、第 2 块自动播完 → 服务端记完成；敬榜样第 1 块播完自动接第 2 块；学知识播到 91% 判完成收工。服务端已完成任务点 18 → 21 / 131。

## 升级

覆盖安装即可，`config.json` 会保留。想更稳一点，建议：

- 播放倍速留在 1.0（1.25 倍是风控最常见的诱因）；
- 浏览器窗口别最小化（「后台静音跑」是把它藏到屏幕外，不是最小化）。

## 还留着的问题

- 纯图片任务点（明要点）网页端不记完成，脚本只能标「需要人工」，得你自己点一下；
- 讨论任务点有时要发一条回复才算完成，生成的内容质量看模型；
- 一个任务点里的视频能不能算完成，最终仍由服务端决定，脚本只能读到页面上的标记。

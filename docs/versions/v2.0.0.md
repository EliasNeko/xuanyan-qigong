# v2.0.0 · 节奏护栏 + 后台静默 + 界面重做

发布：2026-11-18

## 为什么要做这一版

v1.0.1 能刷通章节了，但有两个明显问题：

1. **像机器人**：连着几小时不停、视频一个接一个、答题秒回。真人不会这样。
2. **占屏幕**：脚本的浏览器窗口必须最大化放着，干别的事都没法干。

这一版把「节奏」做成了核心功能，页面重做，还加了后台静默模式。

## 改了什么

### 1) 节奏护栏（新模块 `pace.py`）

| 规则 | 默认值 | 说明 |
| --- | --- | --- |
| 每段时长 | 80 分钟（±15% 抖动） | 到一个长度就停，进入休息 |
| 段间休息 | 40–90 分钟（均值 62） | 休息结束重新点「开始刷课」接着刷 |
| 段内微休息 | 每 25–40 分钟停 40–90 秒 | 连着刷久了会自己停一下 |
| 一门课跑完冷却 | 3.5–5 小时 | 异常中断**不计**冷却，可以马上重试 |
| 每日累计 | 软 5.5 小时提示 / 硬 7.5 小时停 | 软上限只提醒，硬上限才拦 |
| 夜间时段 | 01:00–08:00 | **只提示不建议，不拦** |
| 一次选点上限 | 剩余未完成小节的一半（向下取整，至少 1） | 少选一点更像真人 |
| 课程串联 | 最多 2 门，课间 10–25 分钟 | 串联总时长超 4 小时给提示 |
| 答题延迟 | 常规 1.8–4.2 秒，偶尔更快/更慢 | 两题间隔 0.8–2.5 秒，整套 ≥45 秒，提交前再停 2–6 秒 |

另外：检测到页面出现「今日视频任务点完成数已达上限」这类提示，立刻停手并告诉你。

### 2) 任务点自选

GUI 里点「抓取目录」会把整门课的章节树拉下来（两层：大章节 → 小章节），每个小节前面有 ☐，点一下勾选。
已经完成、还没解锁的小节会标出来不让选；一次选超过一半会拦下来并说明原因。

### 3) 后台静默跑

设置里勾「后台静音跑（浏览器窗口挪到屏幕外）」：

- 浏览器窗口挪到屏幕外（`--window-position=-32000,-32000`），不占你的桌面
- 关掉 Chromium 的后台节流（不可见窗口降频、计时器节流、渲染暂停），免得因为「窗口不可见」被判定离开页面
- 用 CDP `Emulation.setFocusEmulationEnabled` 让页面始终认为自己在前台

### 4) 界面重做

- 配色：淡蓝 + 樱花粉
- 背景：插画壁纸，卡片是半透明磨砂
- 看板娘 **龙音汐**（三态 Q 版立绘）：待机 / 正在刷课 / 出问题
- 标题换成 AI 生成的艺术字（猫耳在「奇」上）
- 图标：龙音汐抱着显示学习通图标的平板
- 所有列表、设置块改成**从壁纸切片出来的磨砂面板**，不再是纯白方块（Tk 的 Treeview 永远刷一块不透明底色，所以自己写了一个画布列表控件）

## 真机验证

- 离线自测：`test_offline` / `test_taskpoint` / `test_pace` / `test_resume` 全绿
- GUI 冒烟 + 打包后 exe 启动截图：界面正常，两盏登录灯和「上次跑到」都能读出来
- 安装包静默安装到 `%LOCALAPPDATA%\玄眼奇工`，快捷方式启动正常

## 升级方式

把新的安装包发给对方，装到同一个目录即可；`config.json` 和登录态都会保留。

## 已知问题

- 画布列表是自己画的，暂时不支持列宽拖动、多选、键盘导航
- 磨砂面板是「壁纸模糊切片」，缩放窗口时图案不会跟着变（窗口尺寸固定，所以看不出来）
- 夜间时段按本机时间算，跨时区不管
- 题面字体加密还原后偶尔仍有个别错字（「空间」还原成「空问」），AI 提示词里已经让它按最接近的意思理解

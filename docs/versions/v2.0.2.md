# v2.0.2 — 列表修好、界面文案不再打架、少一个被误杀的理由

发布日期：2026-11-18

这一版没有新玩法，全是在补 v2.0.0 重做界面时留下的窟窿，外加一个「装到别人电脑上会被杀软误判」的坑。

## 为什么改

1. 点「刷新课程」之后，课程列表和任务点目录**一片空白**。
2. 列表能出来后，好几处文字**叠在一起**（版本号和作者行、豆包说明压到「节奏护栏」标题、
   「静音」复选框和行标题、课程号 9 位数字换行）。
3. 有机器上装好之后点「抓取目录」会**直接没了**，桌面图标也消失 —— 查下来是
   Microsoft Defender 把主 exe 判成 `Trojan:Win32/Bearfoos.A!ml`（机器学习启发式**误报**）。

## 改了什么

### 列表空白（真 bug）
自绘列表 `CanvasList` 的列定义是四元组 `(key, title, width, anchor)`，
但 `redraw()` / `identify_column()` 还按三元组解包，抛
`ValueError: too many values to unpack (expected 3, got 4)`，
异常被界面队列的兜底 except 吞掉，于是「什么都没画出来」。
改成按四元组解包后正常；顺手让点击行时也会选中（原来只有 `on_click` 被转发），
同 iid 重复插入改成原地更新，长文本按列宽裁成「…」不再折行压下一行。

### 文案不再打架（9 处）
- 版本号并进作者行，不再和「看板娘 龙音汐」压在一起；
- 豆包卡片说明改成两行短句，卡片高度收紧，不再侵入「节奏护栏」标题；
- 节奏护栏的副标题删掉（它本来就贴着标题写）；
- 「静音 / 没答案时」「两个开关」行标题缩短、控件右移；
- 课程号列从 88px 加宽到 122px（9 位数字不再换行）；
- 看板娘卡副标题去掉强制宽度，立绘高度按窗口缩放。

### 降低杀软误报
- **不再给 Edge 传 `--no-sandbox`**：Playwright 默认 `chromium_sandbox=False` 会塞这个参数，
  它在杀软眼里是典型的「被恶意程序拉起的浏览器」特征；改成 `chromium_sandbox=True` 后，
  浏览器顶部那句「你使用的是不受支持的命令行标记 --no-sandbox」也一起消失。
- exe 增加 Windows 版本资源（产品名 / 文件版本 / 版权），不再是「三无」二进制。

> 提醒：这一步**降低**概率，不能保证百分百不被误判。真被拦了，只能手动在
> 「Windows 安全中心 → 病毒和威胁防护 → 排除项」里把 `%LOCALAPPDATA%\玄眼奇工`
> 和 `玄眼奇工.exe` 加进去 —— 用脚本加排除项会被安全中心判成「篡改防护」而拦下。

### 打包自检
新增 `LEARN_AUTO_SELFTEST=1` 环境变量：打包后的 exe 不开界面，直接起浏览器打开学习通登录页，
把 `TITLE / URL / OK` 写到 `%LOCALAPPDATA%\LearnAuto\state\selftest.txt`，
用来确认「装到别人电脑上，浏览器这条路没被安全软件掐掉」。

## 验证

- `test_offline` / `test_taskpoint` / `test_pace` / `test_resume` / `test_chain` 全部通过；
- GUI 冒烟（喂 3 门课程 + 3 个小节）后截图，列表有内容、无压字；
- 打包后的自检：`TITLE 用户登录` / `URL https://passport2.chaoxing.com/login?fid=&refer=` / `OK`；
- 安装后启动正常，桌面与开始菜单快捷方式都指向 `%LOCALAPPDATA%\玄眼奇工\玄眼奇工.exe`。

## 升级

直接跑新版安装包覆盖安装即可，`config.json`、登录态（`%LOCALAPPDATA%\LearnAuto`）、
刷课记录都保留。

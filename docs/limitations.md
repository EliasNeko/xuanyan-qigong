# 当前版本的局限

按「会不会影响使用」排序。标 ⛔ 的是**不打算解决**的。

## 课程与页面

1. **只支持学习通**（mooc1.chaoxing.com / mooc-ans / mooc2）。页面结构改版就要跟进选择器，改版当天大概率跑不动。
2. **只处理「视频 / 文档 / 章节测验 / 期中期末试卷 / 填空·简答·计算 / 讨论」这几类任务点**。问卷、投票、直播 / 签到一律跳过（识别得到、不点）；一门课里只有这些之外的页面，脚本会「没有可刷的小节」。
2.1 **讨论区的回复是 AI 按材料现写的**。读得到话题标题和正文，写 120~200 字学生口吻的话发出去；贴合度不如你自己写，也可能和老师的期待对不上。AI 不可用时脚本**默认不发**（不拿模板凑数），想硬发才开 `discuss.allow_template`。
2.2 **讨论任务点认不出「你已经回过了」时会再回一条**。页面和服务器都没给出这个任务点已完成的信号时，脚本宁可再发一次也不跳过（多一条回复不扣分，漏一个任务点会被目录卡住）。
3. **闯关模式必须按顺序**：前一小节没做完，后面的小节是锁着的（onclick 为空），无法跳着刷。

## 视频

4. **禁倍速的课只能原速**。脚本会试 1.25x 并读回，被限制就退回 1.00x —— 不绕学校设置。一小时的长视频就真的是一小时。
5. **窗口不能最小化**。学习通会判「离开页面」，任务点可能不计数；脚本最多只能保证窗口不失去焦点式地播放。
6. **91% / 96% 的判定依赖服务端及时记账**。遇到服务端延迟大，可能会一路播到结尾（白等几分钟）。
6.1 **一个任务点里最多连播 3 段视频**（`run.video_rounds`）。有的课把一整学期的视频塞进一个任务点，剩下的会留到下一轮再播。
6.2 **换段靠「src + 时长」签名**。如果学校给同一段视频换了 CDN 地址而时长完全一样，理论上认不出换段；实际页面里 src 尾部和时长通常都会变。

## 答题

7. **字体加密还原有错字**（实测认领 20/61 ～ 25/67）。「空间→空问」「绘画→绘固」这类错字靠 AI 容错理解，遇到关键字被解错的题就是硬伤。
8. **判断题靠模型知识，教材口径不一致就会错**。例：「20 世纪五六十年代西方绘画开始回归写实主义」被模型判为「错」。提示词改不动。
9. **分数一旦提交就固定**。有些测验交完变成「已批阅」页、没有重做入口，那一节就永久停在 50 分 / 75 分。脚本不会替你点「重做」（会覆盖记录，交给人决定）。
10. **填空 / 简答 / 计算已支持，但答案要模型自己编**。脚本把题干交给 AI 要一段文字填进输入框，质量取决于模型和教材口径，写偏了就是低分；拿不到答案会留空等人补。连线、主观论述这类没有输入框的题仍然无解。
11. **AI 每道题 8～18 秒**，一节 4 题大概 40～60 秒；加上视频，整门课是「小时级」的活。
11.1 **数学题的答案不会自己验算**。AI 算错就是错；填空题没有选项可蒙，算错直接丢分。
11.2 **期中 / 期末一般只有一次机会**。脚本默认「答不齐就不交」（`quiz.submit_partial=false`），但也意味着答不齐时会停在原地等你决定。
11.3 **连线题 / 拖拽题 / 主观论述题仍然无解** —— 这些不是「填一段文字」或「点一个选项」能做的。

## 风控与合规

12. **有被识别与被处罚的风险**。虽然是真实页面、有随机停顿、会降级到原速，但同账号多设备、异常使用时间仍可能触发风控。⛔ 不打算做任何「反检测」对抗。
13. **不提供代刷能力**：不支持批量账号、不支持并发、不提供「跳过风控」的功能。

## 环境

14. **依赖 Edge**（`channel="msedge"`）；没装 Edge 的机器要改配置或换 Chromium。
15. **只做了 Windows 打包**：安装器、快捷方式、卸载都基于 Windows。源码层面跨平台（Playwright 跨平台），但没做验证。
16. **登录态存在本地 profile 里**，换机器要重新扫码；学习通的「下次自动登录」只保 7 天。

## 界面

17. **固定尺寸、不支持拉伸**（按屏幕算缩放，但窗口不能自由改大小）。
18. **没有多语言**，全中文。

- 界面里的列表是自绘的画布控件，暂不支持列宽拖动 / 多选 / 键盘导航
- 磨砂面板是「壁纸模糊切片」，依赖窗口固定尺寸；改成可缩放窗口后需要重算切片
- 夜间时段按本机时间判断，不处理时区与夏令时

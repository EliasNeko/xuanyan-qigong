# 代码片段

这些是从真实实现里**裁剪**出来的片段，目的是让你看清「关键判断长什么样」，不是可直接运行的模块。

| 文件 | 讲什么 |
| --- | --- |
| `read_taskpoints.js` | 从页面读任务点条，判断某个任务点是否已完成 |
| `video_stop_rule.py` | 视频播到 91% / 96% 时问一次「任务点算完成了吗」 |
| `pick_submit_button.py` | 弹题「提交」按钮的选择器打分选优（修死循环的那一段） |
| `exam_check_hidden.js` | 章节测验提交前自检：靠 hidden input 判每题选没选上 |
| `font_reverse.py` | 字体加密还原：按 cmap 认领范围反查 |
| `parse_ai_answer.py` | 从 AI 回复里取「答案=B」 |

约定：片段里省略了日志、异常处理、配置读取，只留判断逻辑本身。
